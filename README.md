# Hydraulik

Model hydrauliczny 2D dla rodziny Hydrografa — pakiet oparty o Deltares HydroMT-SFINCS, przeznaczony przede wszystkim do symulacji **powodzi błyskawicznych w zlewniach górskich** (rain-on-grid, SCS-CN).

Rodzina projektów: [Hydrograf](https://github.com/Daldek//Hydrograf) (hub) · [Kartograf](https://github.com/Daldek//Kartograf) (dane przestrzenne) · [Hydrolog](https://github.com/Daldek//Hydrolog) (obliczenia hydrologiczne) · [IMGWTools](https://github.com/Daldek//IMGWTools) (dane hydrometerologiczne).
